---
title: Manage projects
description: Create, rename and archive projects. Archived projects keep their history and don't count towards your plan.
---

A project is anything you run and want to follow: a website, a plugin, an app or a product. It groups the data sources and events that belong together. Projects are where everything starts: you create the project first, then add its data sources.

## Create a project

1. Select **Add project** on the overview, or in **Settings → Projects**.
2. Enter a **Project name** and, optionally, a **Domain** like `example.com`.
3. Select **Create project**.

You land on the new project. Select **Add data source** to connect its first [data source](../data-sources/).

## Project settings

Each project has its own settings page with its details and its data sources. Open it with **Project settings** on the project page, or from **Settings → Projects** with **Edit project and data sources**.

## Rename or change the domain

Open **Project settings**, change the **Project name** or **Domain** and select **Save project**.

The domain is only a label. It helps you tell projects apart and lets you find them by domain on the overview.

## Archive a project

Archive projects you no longer want on the overview, such as a site you've sold or a finished campaign.

1. Open **Project settings**.
2. Tick **Archive project**.
3. Select **Save project**.

An archived project:

- disappears from the overview but stays listed in **Settings → Projects**, marked *Archived*,
- keeps all its history, and its page still opens,
- stops collecting new data, and **Sync now** is turned off,
- doesn't count towards your plan's project and data source limits.

To bring it back, untick **Archive project** and save. Collection resumes and catches up within each data source's history window.

There's no delete button for projects. Archiving keeps your history safe if you ever need it again. To have data deleted for good, see [Security and privacy](../security/#deleting-your-data).

## Who can manage projects

Owners and editors can create, edit and archive projects. Viewers can see them.
