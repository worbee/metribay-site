Zahlen zeigen dir, *dass* sich etwas verändert hat. Notizen (in der App **Annotations**) helfen dir, dich zu erinnern, *warum*. Leg eine an, wenn du eine Funktion veröffentlichst, eine Kampagne startest, einen Fehler behebst oder auf einen neuen Server umziehst.

## Notiz hinzufügen

1. Öffne das Projekt.
2. Scrolle zu **Annotations** und wähle **Add annotation**.
3. Fülle aus:
   - **Date**: wann es passiert ist. Heute ist schon eingetragen.
   - **Source** *(optional)*: Verknüpfe die Notiz mit einer Datenquelle oder lass **Whole project** stehen.
   - **Title**: eine kurze Beschreibung, etwa „Neue Preisseite online“.
   - **Note** *(optional)*: weitere Details.
   - **Reference URL** *(optional)*: ein Link zu Changelog, Ticket oder Blogartikel.
4. Wähle **Add annotation**.

Notizen stehen auf der Projektseite, die neueste zuerst.

## Bearbeiten oder löschen

Öffne unter einer Notiz **Edit annotation**, um sie zu ändern, oder wähle **Delete annotation**, um sie zu entfernen.

Eigentümer und Bearbeiter können Notizen anlegen, ändern und löschen. Leser können sie lesen.

## GitHub-Releases

Hat ein Projekt eine [GitHub-Datenquelle](../integrations/github/), wird jedes veröffentlichte Release automatisch zur Notiz, datiert auf den Tag der Veröffentlichung. Titel ist der Name des Releases (oder sein Tag), die Notiz ist die Release-Beschreibung, und der Link führt zum Release auf GitHub. Vorabversionen sind gekennzeichnet, Entwürfe werden übersprungen.

Metribay hält diese Notizen mit GitHub abgestimmt. Bearbeitest oder löschst du dort ein Release, zieht die Notiz bei der nächsten Synchronisierung nach.

## Ideen für gute Notizen

- Releases, Launches und Redesigns
- Marketingkampagnen, Newsletter und Social-Media-Beiträge, die gut liefen
- Updates der Suchmaschinen, von denen du gelesen hast
- Ausfälle, Umzüge sowie Änderungen an DNS oder Hosting
- Änderungen am Tracking, etwa ein neues Consent-Banner oder eine neue Analytics-Einrichtung

Der letzte Punkt ist wichtiger, als er aussieht. Ein plötzlicher Einbruch bei den Besuchern ist oft eine Änderung am Tracking und kein echter Rückgang.
