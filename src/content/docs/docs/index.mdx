Metribay is a dashboard for the projects you run. It reads numbers from the tools you already use, such as Google Analytics, Search Console, GitHub and UptimeRobot, and shows them side by side. You see how every project is doing without opening a tab for each tool.

Metribay doesn't replace those tools. It only reads from them, and it never changes anything in them.

## What you can do with Metribay

- **See every project at once.** The overview lists each project with its latest numbers, small trend charts and a health status for each source.
- **Compare periods.** Switch between the last 7, 30 or 90 days and see the change against the period before.
- **Remember why things changed.** Add annotations for launches, campaigns or fixes. GitHub releases appear on their own.
- **Work as a team.** Invite people to a workspace as owners, editors or viewers. *(Metribay Cloud)*
- **Trust what you see.** Metribay shows missing data as missing, marks recent days that providers may still revise, and never adds up numbers that can't be added.

## Ways to run Metribay

| | Metribay Cloud | Self-hosted |
|---|---|---|
| Where it runs | Hosted for you in the EU at [app.metribay.com](https://app.metribay.com/) | Your own server |
| People | Up to 5 workspaces with 10 members each | One person, one workspace |
| Projects and sources | 10 active projects, 50 active sources | No limit |
| Updates and backups | Done for you | Your job |

Both editions have the same dashboard and the same integrations. See [Plans and billing](billing/) and [Run Metribay yourself](self-hosting/).
