Follow the downloads of any plugin in the [WordPress.org plugin directory](https://wordpress.org/plugins/), yours or anyone else's. It's public data, so there's nothing to set up.

## What you get

| Metric | Meaning | Period value |
|---|---|---|
| **Downloads** | Downloads per day, as published by WordPress.org | Sum of the days |

Days are counted in UTC. Today is still in progress and is marked as partial.

## Connect a plugin

<Steps>

1. Select **Add source** and choose **WordPress.org**.

2. Type the plugin's name into **Plugin name** and select **Search plugins**.

3. Choose the plugin from the results.

4. Pick a project and select **Connect and start import**.

</Steps>

### Enter the plugin by hand

Open **Enter a resource manually** and type the **Plugin slug**: the last part of the plugin's address. For `https://wordpress.org/plugins/query-monitor/`, the slug is `query-monitor`.

## Good to know

- **Plugins only.** Themes aren't supported.
- **Try Metribay with it.** Because it needs no account, WordPress.org is the quickest way to see Metribay working. Add any popular plugin to a test project.
- **Editors can add it too.** Since there are no credentials involved, editors can add WordPress.org sources without an owner.
- **Downloads aren't installs.** WordPress.org counts downloads, including automatic updates. They're a good trend signal, not a count of active sites.
