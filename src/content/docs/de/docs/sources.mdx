Eine Datenquelle bringt die Zahlen eines Anbieters in ein Projekt. Eine typische Website hat drei: Google Analytics für Besuche, Search Console für die Suche und UptimeRobot für die Verfügbarkeit.

## Datenquelle hinzufügen

Wähle **Add source** in der Übersicht, auf einer Projektseite oder unter **Settings → Sources**. Startest du auf einer Projektseite, landet die Datenquelle in diesem Projekt.

<Steps>

1. **Provider.** Wähle, wo deine Daten liegen. Siehe [alle Integrationen](../integrations/).

2. **Account.** Wähle unter **Saved account** ein gespeichertes Konto oder öffne **Use your own credentials**, um ein neues hinzuzufügen. Metribay prüft die Zugangsdaten, bevor es sie speichert. Die [Anleitung zu deiner Integration](../integrations/) erklärt, welche Zugangsdaten du brauchst.

3. **Resource.** Metribay listet die Websites, Properties, Repositorys oder Monitore, die dieses Konto sehen kann. Nutze den Filter und wähle eine aus.

   Fehlt deine, prüfe, ob das Konto Zugriff darauf hat, und wähle dann **Refresh resources**. Du kannst auch **Enter a resource manually** öffnen und die ID eintippen.

4. **Connect.** Wähle das **Project**: ein vorhandenes oder **Create a new project** mit Namen und optionaler Domain. Unter **Advanced settings** legst du eine Bezeichnung (**Source label**) und den Verlaufszeitraum (**History window (days)**) fest. Die Zeitzone wird dir zur Information angezeigt.

   Wähle **Connect and start import**.

</Steps>

Neue Projekte entstehen erst, wenn du diesen letzten Schritt bestätigst. Brichst du früher ab, wird nichts angelegt.

### Pausieren und weitermachen

- **Save for later** merkt sich deinen Fortschritt eine Stunde lang in diesem Browser. Wähle wieder **Add source**, um weiterzumachen.
- **Change provider** beginnt mit einem anderen Anbieter von vorn.
- **Choose another resource** geht von der Bestätigung einen Schritt zurück.

### Wer Datenquellen hinzufügen kann

| | Eigentümer | Bearbeiter | Leser |
|---|---|---|---|
| Datenquelle mit neuem Konto hinzufügen | ✓ | | |
| Datenquelle mit gespeichertem Konto hinzufügen | ✓ | ✓ (Ressource von Hand eintragen) | |
| WordPress.org-Datenquelle hinzufügen | ✓ | ✓ | |

Nur Eigentümer können Konten hinzufügen und alles durchsuchen, was ein Konto sehen kann, denn dabei geht es um Zugangsdaten. In der selbst gehosteten Version bist du der Eigentümer.

## Datenquelle verwalten

Geh zu **Settings → Sources**. Jede Datenquelle zeigt Projekt, Anbieter, Zeitzone, Ressourcen-ID, die Zeit der letzten Synchronisierung und das letzte Erfassungsproblem. Öffne **Manage source**, um Folgendes zu ändern:

- **Source label**: der Name im Dashboard.
- **Collection window (days)**: der [Verlaufszeitraum](../syncing/#der-verlaufszeitraum), von 1 bis 366 Tagen.
- **Connection**: das gespeicherte Konto, das diese Datenquelle nutzt. Der Verlauf bleibt beim Wechsel erhalten. Praktisch, wenn du Zugangsdaten erneuerst oder auf ein neues Dienstkonto umziehst.
- **Collect automatically**: ausschalten, um die Datenquelle zu pausieren. Sie behält ihren Verlauf.

Wähle **Save source**, um zu speichern. Unter dem Formular findest du **Sync now** und, für Eigentümer, **Check provider access**. Siehe [Aktualisierung und Sync](../syncing/).

## Ändern, was eine Datenquelle verfolgt

Anbieter, Ressource und Zeitzone einer Datenquelle stehen nach dem Anlegen fest. So bleibt ihr Verlauf stimmig: Ein Jahr Daten einer Property wird nie mit denen einer anderen vermischt.

Willst du eine andere Property, ein anderes Repository oder einen anderen Monitor verfolgen, leg eine neue Datenquelle an und pausiere die alte. Beide behalten ihren eigenen Verlauf.

## Datenquelle entfernen

Für Datenquellen gibt es keinen Löschen-Button. Pausiere die Datenquelle stattdessen: Schalte **Collect automatically** aus. Sie erfasst dann nichts mehr, zählt nicht mehr für die Grenzen deines Plans und behält ihren Verlauf, falls du ihn noch brauchst.

## Mehrere Datenquellen derselben Art

Du kannst einem Projekt beliebig viele Datenquellen hinzufügen, auch zwei vom selben Anbieter. Eine Website, die von Umami zu Google Analytics gewechselt ist, kann zum Beispiel beide zeigen. Gib jeder eine eindeutige Bezeichnung.
