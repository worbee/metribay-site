This guide takes you from no account to your first chart. It takes about five minutes, plus however long your first import runs.

## 1. Create your account

<Steps>

1. Open [app.metribay.com/register](https://app.metribay.com/register) and enter your name and email address.

2. Check your inbox for an email from Metribay. The link in it works for one hour.

3. Open the link and choose a password with at least 14 characters.

4. Sign in with your email address and new password.

</Steps>

Metribay creates your first workspace for you. You land on an empty project overview.

:::tip[No email?]
Check your spam folder, then try again from the sign-up page. For privacy reasons the sign-up page never says whether an address already has an account. If you signed up before, use **Forgot password** on the sign-in page instead.
:::

## 2. Create your first project

A project is one website, app or product you want to follow.

<Steps>

1. Select **Create your first project** on the overview.

2. Enter a **Project name** and, optionally, a **Domain**, then select **Create project**.

</Steps>

## 3. Add your first data source

A data source is one thing Metribay tracks for the project, such as a Search Console property or a GitHub repository. It reads through a connected account: your login at that provider.

<Steps>

1. On the project page, select **Add data source**.

2. **Provider.** Choose where your data lives. If you just want to try Metribay, pick **WordPress.org**. It needs no account: search for any plugin by name.

3. **Connected account.** Sign in with the provider, choose an account you connected before, or enter credentials for a new one. Each [integration guide](../integrations/) explains exactly what to enter.

4. **What to track.** Pick the website, property, repository or monitor you want to track. Metribay lists only what this account can actually see. You can also enter one by hand.

5. **Confirm.** Select **Add and start import**.

</Steps>

If you leave before the last step, the setup starts fresh next time. Accounts you already saved stay under **Settings → Connected accounts**.

## 4. Wait for the first import

The first import reads up to 180 days of history. It runs in the background, so you can close the page. Most data sources finish within a few minutes. Large GitHub repositories and long history windows take longer.

While you wait, the overview shows a short checklist and the data source shows **Awaiting first sync**. When the import finishes, your numbers and charts appear.

## 5. Make it yours

- [Add more data sources](../data-sources/) to the same project. A website might have Google Analytics, Search Console and an uptime monitor.
- [Add events](../events/) for launches and changes, so you remember why a chart moved.
- [Invite your team](../team/) as editors or viewers.
- Prefer German? Switch the [language](../profile/#language) in your profile.
- [Turn on two-factor authentication](../profile/#two-factor-authentication) for your account.

## What happens next

Metribay checks your data sources every four hours, and uptime monitors every hour. You don't need to do anything. See [Updates and syncing](../syncing/) for the details.
