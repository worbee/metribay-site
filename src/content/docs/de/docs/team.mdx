Lade Kolleginnen, Kunden oder Partner ein, damit sie mitverfolgen können. Jede Person bekommt eine Rolle, die festlegt, was sie darf.

:::note[Metribay Cloud]
Teams gibt es mit Metribay Cloud. Die selbst gehostete Version ist für eine Person gedacht.
:::

## Rollen

| Was sie dürfen | Eigentümer (Owner) | Bearbeiter (Editor) | Leser (Viewer) |
|---|:---:|:---:|:---:|
| Übersicht, Projekte, Diagramme und Ereignisse sehen | ✓ | ✓ | ✓ |
| Projekte, Datenquellen und Ereignisse anlegen und bearbeiten | ✓ | ✓ | |
| Datenquellen synchronisieren, Konfiguration importieren und exportieren | ✓ | ✓ | |
| Verbundene Konten (Zugangsdaten) anlegen und bearbeiten | ✓ | | |
| Leute einladen, Rollen ändern und Zugriff entziehen | ✓ | | |
| Arbeitsbereich umbenennen | ✓ | | |

Wer den Arbeitsbereich angelegt hat, ist sein **Eigentümer des Arbeitsbereichs**. Diese Person bleibt immer Eigentümer, damit stets jemand für den Arbeitsbereich verantwortlich ist, und die Abrechnung läuft über ihr Konto. Du kannst weitere Personen zu Eigentümern machen. Sie haben dieselben Rechte, können den Workspace owner aber nicht entfernen.

**Welche Rolle passt?** Leser für Kunden und Beteiligte, die nur die Zahlen sehen wollen. Bearbeiter für Teammitglieder, die Projekte einrichten. Eigentümer nur für Personen, denen du deine Zugangsdaten bei Anbietern anvertrauen würdest.

## Jemanden einladen

<Steps>

1. Öffne den Arbeitsbereich und wähle in der Navigation **Team**.

2. Gib unter **Teammitglied einladen** die **E-Mail-Adresse** ein und wähle eine **Rolle**.

3. Wähle **Einladung erstellen**.

4. Metribay verschickt die Einladung per E-Mail. Zusätzlich siehst du den Einladungslink einmal und kannst ihn auf anderem Weg privat weitergeben.

</Steps>

Einladungen laufen nach 72 Stunden ab. Eine offene Einladung belegt einen Platz, bis sie angenommen, zurückgezogen oder abgelaufen ist. Brauchst du einen neuen Link, erstell die Einladung erneut: Der alte Link funktioniert dann nicht mehr.

## Einladung annehmen

<Steps>

1. Öffne den Link aus der Einladung.

2. Melde dich an oder [leg zuerst ein Konto an](../getting-started/), und zwar **mit der E-Mail-Adresse, an die die Einladung ging**.

3. Wähle **Einladung annehmen**. Ist das Feld für den Code leer, öffne den Link noch einmal im selben Browser.

</Steps>

Der Arbeitsbereich erscheint dann in deinem Umschalter.

## Rolle ändern oder jemanden entfernen

Wähle auf der Seite **Team** neben der Person eine neue **Rolle** und dann **Rolle speichern**. Um den Zugriff zu entziehen, wähle **Zugriff entfernen**. Ihre Änderungen und Ereignisse bleiben im Arbeitsbereich.

Eine noch nicht angenommene Einladung ziehst du unter **Offene Einladungen** mit **Einladung widerrufen** zurück.

## Plätze

Jeder Arbeitsbereich bietet Platz für 10 Personen, einschließlich des Workspace owners. Offene Einladungen zählen mit.

## Teilen braucht einen aktiven Plan

Geteilter Zugriff hängt vom Metribay-Cloud-Plan des Workspace owners ab. Endet dessen Testzeitraum oder Abonnement, verlieren die Mitglieder den Zugriff auf den Arbeitsbereich, bis er wieder aktiv ist. Es wird nichts gelöscht, und die Mitglieder kommen mit denselben Rollen zurück. Siehe [Pläne und Abrechnung](../billing/).
