[Umami](https://umami.is/) is a privacy-friendly, open-source analytics tool. Metribay reads from Umami servers you host yourself.

## What you get

| Metric | Meaning | Period value |
|---|---|---|
| **Visitors** | Unique visitors | Exact unique visitors for the whole period, from Umami |
| **Visits** | Visits (sessions) | Sum of the days |
| **Page views** | Page views | Sum of the days |

Days are counted in UTC. Umami's own dashboard uses your browser's timezone, so single days can differ slightly. Period totals line up.

## Before you start

:::caution[Self-hosted Umami only]
Metribay signs in to Umami with a username and password, which works with self-hosted Umami. **Umami Cloud** uses API keys instead and isn't supported yet.
:::

Your Umami server must be reachable from the internet:

- over **HTTPS** on the standard port 443,
- at a public address. Servers on a private network, behind a VPN or only reachable by IP inside your network can't be reached.

## Step 1: Create a user for Metribay

You can use your own Umami login, but a separate user is safer: it keeps your admin password out of Metribay, and you can remove it at any time.

<Steps>

1. In Umami, go to **Settings → Users** and create a user, for example `metribay`, with the **View only** role.

2. Give that user access to the websites you want to track. In Umami that usually means adding them to the team that owns the websites.

3. Sign in as the new user once to check it can see the websites.

</Steps>

## Step 2: Connect it in Metribay

<Steps>

1. On the project page, select **Add data source** and choose **Umami**.

2. Open **Connect an account with your own credentials** and fill in:
   - **Server URL**: the address you open Umami at, like `https://analytics.example.com`. Leave off `/login` or any other path.
   - **Username** and **Password** of the user from step 1.

3. Select **Save account and continue**. Metribay signs in to check the details.

4. Choose a website from the list. You can search by name or domain.

5. Select **Add and start import**.

</Steps>

### Enter the website by hand

Open **Enter it manually** and paste the **Website UUID**. In Umami, find it under **Settings → Websites → Edit** as the **Website ID**, for example `4fb7fa4c-5b46-438d-94b3-3a8fb9bc2e8b`.

## If collection fails

**“Use a public HTTPS server URL on port 443.”** The address starts with `http://`, has a port number like `:3000`, or has extra parts. Use the plain `https://` address.

**The website isn't listed.** The user can't see it. Check its access in Umami, then select **Refresh list**.

**“Needs attention” after it worked.** The user's password may have changed, or the server may be unreachable. Sign in to Umami with the same details to check, then [update the connected account](../../connected-accounts/#update-or-rotate-credentials).

See also [Troubleshooting](../../troubleshooting/).
